# Néstor Ramos | Portafolio Profesional

Portafolio digital interactivo de *Néstor Ramos*, Contador Público.  
Diseñado para mostrar servicios contables y fiscales de forma clara, moderna y orientada a la conversión.

🔗 *Sitio en vivo:* [https://NestorRamos.github.io/nombre-del-repositorio](https://NestorRamos.github.io/nombre-del-repositorio)

---

## ✨ Características

- Diseño moderno y responsive (móvil, tablet y escritorio)
- Modo claro / oscuro
- Filtros de servicios por categoría
- Tarjetas de servicios expandibles
- *Calculadora de honorarios* interactiva (en pesos colombianos)
- Enlaces directos a WhatsApp con mensajes predefinidos
- Botón flotante de WhatsApp con animación
- Sección de proceso de trabajo
- Preguntas frecuentes (FAQ) tipo acordeón
- Optimizado para velocidad y buena experiencia de usuario

---

## 🛠️ Tecnologías utilizadas

- HTML5
- Tailwind CSS (CDN)
- JavaScript vanilla
- Font Awesome
- CSS personalizado (styles.css)
